# Glossary of Terms

## Project: Performance Appraisal and Bell-Curve Normalisation with Increment Bands

This glossary explains the important terms used in the project. It provides a common understanding of the appraisal process, performance calculations and salary-related concepts used in the system.

| Term | Description |
|---|---|
| Performance Appraisal | A process used by an organisation to evaluate an employee's performance over a particular period. |
| Employee ID | A unique identification number assigned to each employee. |
| Business Unit (BU) | A department or division within an organisation, such as IT, Finance or HR. |
| Grade | The level assigned to an employee based on their position and responsibilities. In this project, grades range from G1 to G7. |
| Basic Salary | The fixed salary amount paid to an employee before additional benefits and variable payments. |
| Goal | A target or task assigned to an employee that is used to measure their work performance. |
| Goal Weight | The percentage of importance assigned to a particular goal during appraisal. The total weight of an employee's goals must be 100%. |
| Self Rating | The performance score given by an employee while evaluating their own work. |
| Manager Rating | The performance score given by an employee's manager based on the employee's work and achievements. |
| Competency | A skill, ability or behaviour used to evaluate how well an employee performs their role. |
| Competency Score | The average score calculated from the manager's ratings for an employee's competencies. |
| Goal Score | The weighted score calculated using the manager's ratings for the employee's goals. |
| Raw Score | The initial appraisal score calculated using 70% goal score and 30% competency score, before bell-curve normalisation. |
| Eligibility | The condition that determines whether an employee can participate in a particular appraisal cycle. |
| Appraisal Cycle | The specific period during which employee performance is evaluated. |
| Bell-Curve Normalisation | A method of distributing employee performance ratings according to predefined percentages rather than assigning ratings only from individual scores. |
| Rating Distribution | The percentage or number of employees assigned to each final performance rating. |
| Rating 5 | The highest performance category in the appraisal system. |
| Rating 4 | A performance category assigned to employees in the next group below rating 5. |
| Rating 3 | The middle performance category in the rating distribution. |
| Rating 2 | A lower performance category assigned to employees who fall below the middle group. |
| Rating 1 | The lowest performance category in the rating distribution. |
| Tie-Breaking | A method used to decide the ranking of employees when they have the same appraisal score. |
| Tenure | The length of time an employee has worked in the organisation or in their current grade. |
| Increment | An increase in an employee's basic salary based on their final appraisal rating and applicable rules. |
| Increment Percentage | The percentage by which an employee's basic salary is increased. |
| Revised Basic Salary | The employee's new basic salary after applying the eligible increment. |
| Prorated Increment | An increment adjusted according to the number of completed months an employee has worked during the appraisal cycle. |
| Salary Band | The minimum and maximum salary range defined for a particular employee grade. |
| Salary Cap | The maximum basic salary allowed for a particular grade. |
| Lump Sum | A one-time payment made separately instead of adding the amount to the employee's regular basic salary. |
| Promotion | The movement of an employee from their current grade to a higher grade based on the organisation's promotion rules. |
| Variable Pay | An additional payment given to an employee based on performance, grade and company performance. |
| Variable Pay Target | The percentage of annual basic salary used as the starting point for calculating variable pay. |
| Rating Multiplier | A value applied to the variable pay calculation based on the employee's final performance rating. |
| Company Multiplier | A value that adjusts variable pay according to the organisation's overall performance. |
| Performance Improvement Plan (PIP) | A structured plan designed to help employees improve their performance when they do not meet the expected standards. |
| Appeal | A request made to review an appraisal rating when an employee or manager believes that a rating needs reconsideration. |
| Recalibration | The process of calculating the rating distribution again after approved appraisal changes. |
| Budget Constraint | A financial limit that the organisation sets for employee increments within a business unit. |
| Budget Scaling | The process of proportionally reducing increment percentages when the total increment cost exceeds the available budget. |
| CSV (Comma-Separated Values) | A file format used to store tabular data, such as employee details, goals and ratings. |
| Validation | The process of checking input data to ensure that it follows the required rules before processing. |
| Unit Testing | Testing individual parts of a program to check whether they produce the expected results. |
| Business Rule | A condition or requirement that defines how the appraisal system should behave. |
